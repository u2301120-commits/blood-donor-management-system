BLOOD DONOR MANAGEMENT SYSTEM - RUN INSTRUCTIONS

1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run: python -m pip install -r requirements.txt
4. Run: python app.py
5. Open: http://127.0.0.1:5000

The application uses SQLite (donors.db) and automatically adds missing columns when an older database is used.

The screening rules in this academic prototype are project rules only; final donor eligibility must be confirmed by authorized blood-centre medical staff.
